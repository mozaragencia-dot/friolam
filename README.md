# Friolam (Ionic + Node)

Se migró el proyecto a una web app en **Ionic** con backend en **Node.js + Express**, usando archivo de base de datos JSON (`server/db.json`).

## Ejecutar local

```bash
npm install
npm start
```

Abre: `http://localhost:8000`

## API

- `GET /api/dashboard`
- `GET /api/records`
- `POST /api/records`

## Tests

```bash
npm test
```
